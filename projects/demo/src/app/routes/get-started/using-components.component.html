Get started

Using components

ngx-govuk components are standalone Angular components and directives. Import the ones you need into your own components, then use them in your templates.

Import components

Each component has its own entry point, such as "ngx-govuk/button", so your app only bundles the components it imports. Import them where you use them, and add them to your component's "imports" array.

Each component's page shows what to import, in its API section. See the components page for every component.

Inputs and outputs

Set inputs and listen to outputs in the usual Angular way.

Properties and methods

Some components expose properties and methods. Use a template reference variable to reach the component instance.

Form fields

Form fields, such as text inputs, go inside a form group, which adds the label, hint and error message. See Working with forms.
