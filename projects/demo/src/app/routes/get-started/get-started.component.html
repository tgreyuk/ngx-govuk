Requirements

  • Angular 22
  • GOV.UK Frontend (the "govuk-frontend" package) 6

Install packages from npm

Install ngx-govuk together with GOV.UK Frontend. ngx-govuk renders GOV.UK Frontend's markup, and GOV.UK Frontend provides the styles. 


  


  

    
Add GOV.UK classes to the page

    

      In your "index.html" file, add "govuk-template" to the html tag, and
      "govuk-template__body" and "govuk-frontend-supported" to the body tag.
      GOV.UK Frontend's page template uses these classes to set the page
      background and text sizing.
    

    

      GOV.UK's page template adds "govuk-frontend-supported" with a small inline
      script. The accordion and tabs styles depend on it, and without it they
      show their no-JavaScript fallback. ngx-govuk components do not need that
      script, so add the class directly.
    

    

  


  

    
Include GOV.UK styles

    

      ngx-govuk does not ship any styles of its own. Include
      GOV.UK Frontend's styles
      in one of these ways.
    


    
Recommended: load all styles with Sass

    

      Load GOV.UK Frontend in your global "styles.scss" stylesheet. GOV.UK
      Frontend 6 uses Sass modules, so use "@use" rather than "@import".
      Loading it with Sass lets you choose the font (see
      Choose a font).
    

    


    
Load only the styles you use

    

      To keep your CSS smaller, load the base styles once and then only the
      components you use. This example loads the styles for buttons, details and
      text inputs.
    

    


    
GOV.UK services: use the precompiled CSS

    

      GOV.UK Frontend also ships a precompiled stylesheet. It is the quickest
      setup, but it always uses the GDS Transport font, which is for services on
      service.gov.uk. Add it to the "styles" array in "angular.json", and copy
      GOV.UK Frontend's fonts and images with an "assets" entry so the font
      files load.
    

    

    

      Angular's build may warn about a CSS syntax error in this file. It comes
      from an old Internet Explorer workaround in GOV.UK Frontend's stylesheet
      and is harmless.
    

  


  

    
Choose a font

    

      GOV.UK Frontend uses the GDS Transport font by default. Services on
      service.gov.uk must use it. Services publicly available on other domains
      should use an alternative typeface. See the
      GOV.UK typeface guidance.
    

    

      To use an alternative, set "$govuk-font-family" when loading GOV.UK
      Frontend with Sass. GOV.UK recommends the font stack shown below, or your
      own brand's font. When GDS Transport is not in the font list, GOV.UK
      Frontend leaves out its font files entirely, so there is nothing to copy
      and no missing-font errors.
    

    

    

      When loading only some styles, add the same "with" to the "base" line, as
      shown above.
    

    

      If your service is not on GOV.UK, also read
      Using GOV.UK Frontend without GOV.UK branding, which covers changing the brand colour in the same "with".
    

  


  

    
Use components

    

      Each component has its own entry point, such as "ngx-govuk/button", so
      your app only bundles the components it imports. Import them where you use
      them.
    

    

    

      See the
      components page for
      every component and its API.
    


    
Inputs and outputs

    

      Set inputs and listen to outputs in the usual Angular way.
    

    


    
Properties and methods

    

      Some components expose properties and methods. Use a template reference
      variable to reach the component instance.
