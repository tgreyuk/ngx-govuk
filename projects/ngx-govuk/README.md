# ngx-govuk

![npm](https://img.shields.io/npm/v/ngx-govuk?&logo=npm) [![Build Status](https://github.com/tgreyuk/ngx-govuk/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/tgreyuk/ngx-govuk/actions/workflows/ci.yml)

[GOV.UK Design System](https://design-system.service.gov.uk) components for Angular projects.

ngx-govuk is a community resource of the GOV.UK Design System. The Design System team is not responsible for it and cannot support you with using it. Contact the ngx-govuk maintainers through [GitHub issues](https://github.com/tgreyuk/ngx-govuk/issues) if you need help.

## Installation

```shell
npm install ngx-govuk govuk-frontend
```

ngx-govuk renders GOV.UK Frontend markup and uses its styles, so `govuk-frontend` is a peer dependency. See [Get started](https://ngx-govuk.org/get-started) for setting up the styles.

## Compatibility

| ngx-govuk | Angular | govuk-frontend |
| --------- | ------- | -------------- |
| 0.5.x     | 22.x    | 6.x            |
