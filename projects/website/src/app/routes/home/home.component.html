Build Angular apps with GOV.UK Design System components

ngx-govuk is a library of Angular components for the GOV.UK Design System.

Built for Angular 22, it works with reactive and template-driven forms and renders GOV.UK Frontend's markup and styles unchanged.

It is a community project, not made or supported by the GOV.UK Design System team.
