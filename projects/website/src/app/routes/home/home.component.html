Build Angular apps with GOV.UK Design System components

ngx-govuk is a library of Angular components for the GOV.UK Design System.

It is a community project, not made or supported by the GOV.UK Design System team.

Features

  • Built for Angular 22, with signal-based APIs.
  • Works with reactive and template-driven forms.
  • Renders GOV.UK Frontend's markup and uses its styles unchanged, including all its accessibility features.
  • One import path per component, so your app only bundles what it uses.
  • Examples and an API reference for every component.
