ngx-govuk

Angular components for the GOV.UK Design System.

ngx-govuk is a community project. It is not made or supported by the GOV.UK Design System team.

Features

  • Built for Angular 22 with signal-based APIs.
  • Compatible with reactive forms.
  • Tree-shakeable components utilising secondary entry points.
  • Accurate markup including all accessibility features.
  • Uses 100% of GOV.UK styles.
  • Simple to use with comprehensive documentation.
  • Fully tested.
