Build Angular apps with GOV.UK Design System components

ngx-govuk is a library of Angular components for the GOV.UK Design System.

Built for Angular 22, it works with reactive and template-driven forms and renders GOV.UK Frontend's markup and styles unchanged.

Get started →

About ngx-govuk

ngx-govuk is a community resource of the GOV.UK Design System. The Design System team is not responsible for it and cannot support you with using it. Contact the ngx-govuk maintainers directly through GitHub issues if you need help or you want to request a feature.
