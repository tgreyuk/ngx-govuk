Help and support

ngx-govuk is a community project. It is not made or supported by the GOV.UK Design System team, who cannot help you with using it. Its maintainers answer questions and requests on GitHub.

Getting help

Raise an issue on GitHub to:

  • report a bug
  • ask a question about using ngx-govuk
  • request a component or feature

For questions about the GOV.UK Design System itself, such as when to use a component, see the GOV.UK Design System.

Contributing

Pull requests are welcome. Read Contributing to ngx-govuk for how to set up the project and make a change.

Supported versions

ngx-govuk Angular GOV.UK Frontend
0.5.0 and later 22 6

Each release supports the current major versions of Angular and GOV.UK Frontend. When a new major version of either comes out, a new ngx-govuk minor release adds support for it and drops the previous one. Until 1.0.0, earlier ngx-govuk versions are not maintained.
