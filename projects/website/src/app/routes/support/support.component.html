Help and support

ngx-govuk is a community resource of the GOV.UK Design System. The Design System team is not responsible for it and cannot support you with using it. Contact the ngx-govuk maintainers directly through GitHub issues if you need help or you want to request a feature.

Getting help

Raise an issue on GitHub to:

  • report a bug
  • ask a question about using ngx-govuk
  • request a component or feature

For questions about the GOV.UK Design System itself, such as when to use a component, see the GOV.UK Design System.

Supported versions

The current release of ngx-govuk supports Angular 22 and GOV.UK Frontend 6. Each release supports the current major versions of both. See the version policy.
