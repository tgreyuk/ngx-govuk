Installing ngx-govuk

Add ngx-govuk and GOV.UK Frontend to your Angular app, then set up the page, styles and font that GOV.UK's components expect.

Requirements

  • Angular 22
  • GOV.UK Frontend (the govuk-frontend package) 6

Install packages from npm

Install ngx-govuk together with GOV.UK Frontend. ngx-govuk renders GOV.UK Frontend's markup, and GOV.UK Frontend provides the styles.

Add the ngx-govuk provider

Add provideNgxGovuk() to the providers in your app's config. It takes the place of GOV.UK Frontend's initAll().

It adds the classes GOV.UK Frontend's page template puts on the page: govuk-template on the html element and govuk-template__body on the body, which set the page's background and text sizing. You do not need to add them to your index.html file.

When your app starts in the browser, it also adds govuk-frontend-supported to the body, as the page template does with a small inline script. The styles for the accordion, tabs and conditionally revealed questions depend on it, and without it they show their no-JavaScript fallback. With server-side rendering, this class is only added in the browser, so users without JavaScript still get the fallback.

You only need GOV.UK Frontend's styles. Do not load its JavaScript or call initAll(): ngx-govuk components handle their own behaviour, and they do not have the data-module attributes GOV.UK Frontend's scripts look for, so the scripts would do nothing.

Page layout

In your root component's template, put the page's content in a govuk-width-container and a main element with govuk-main-wrapper, as GOV.UK's page template does. These set the page's width and spacing. The header and footer go outside them, since they set their own width.

Put the header and service navigation in a header element with govuk-template__header, and the footer in a footer element with govuk-template__footer. GOV.UK's header and footer components don't include these elements, which tell screen reader users where the page's header and footer are.

Include GOV.UK styles

ngx-govuk does not ship any styles of its own. Include GOV.UK Frontend's styles in one of these ways.

Recommended: load all styles with Sass

Load GOV.UK Frontend in your global styles.scss stylesheet. GOV.UK Frontend uses Sass modules, so use @use rather than @import.

The example replaces GOV.UK's GDS Transport font, which only services on service.gov.uk may use. On service.gov.uk, leave out the with to keep it. See Choose a font.

Copy GOV.UK Frontend's images with an assets entry in angular.json. The footer's styles load the Royal Arms above the copyright notice from /assets/images/govuk-crest.svg.

Load only the styles you use

To keep your CSS smaller, load the base styles once and then only the components you use. This example loads the styles for buttons, details and text inputs.

Quickest: use the precompiled CSS

GOV.UK Frontend also ships a precompiled stylesheet. It is the quickest setup, but it always uses the GDS Transport font, which is for services on service.gov.uk. Add it to the styles array in angular.json, and copy GOV.UK Frontend's fonts and images with an assets entry so the font files load.

Angular's build warns about a CSS syntax error in this file, Expected "{" but found "(". It comes from an old Internet Explorer workaround in GOV.UK Frontend's details styles and does not affect your app. The Sass options don't cause it.

Choose a font

GOV.UK Frontend uses the GDS Transport font by default. Services on service.gov.uk must use it. Services publicly available on other domains should use an alternative typeface. See the GOV.UK typeface guidance.

To use an alternative, set $govuk-font-family when loading GOV.UK Frontend with Sass. The Sass examples above already do this, with the font stack GOV.UK Frontend recommends. Change it to your own brand's font if you have one. When loading only some styles, set it on the base line.

When GDS Transport is not in the font list, GOV.UK Frontend leaves out its font files entirely, so there is nothing to copy and no missing-font errors. If you keep GDS Transport, copy its font files with the same assets entry as the precompiled CSS.

If your service is not on GOV.UK, also read Using GOV.UK Frontend without GOV.UK branding, which covers changing the brand colour in the same with.
